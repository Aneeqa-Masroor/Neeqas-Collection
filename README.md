Neeqas Collection – E-commerce Catalog Page

A stylish, responsive, and user-friendly E-commerce Catalog Page developed using HTML, CSS, JavaScript, and Bootstrap. This project allows users to browse products, search for items, filter products by category, sort prices, and manage their shopping cart through interactive controls.

✨ Features

🛍️ Product Catalog – Display products in an organized and attractive layout.

🔍 Search Functionality – Search for products by name.

🗂️ Category Filtering – Filter products based on selected categories.

💰 Price Sorting – Sort products by price from low to high or high to low.

🛒 Add to Cart – Add products to the shopping cart.

➕ Increase Quantity – Increase the quantity of products in the cart.

➖ Decrease Quantity – Decrease the quantity of products in the cart.

🗑️ Remove from Cart – Delete products from the shopping cart.

🔢 Quantity Management – Manage product quantities using plus and minus controls.

📱 Responsive Design – Optimized for desktops, tablets, and mobile devices.

🎨 Modern User Interface – Clean design with an intuitive shopping experience.

⚡ Interactive Functionality – JavaScript-powered product filtering, sorting, searching, and cart management.

🛠️ Technologies Used

HTML5 – Structures the product catalog and page content.

CSS3 – Provides styling, layouts, and visual enhancements.

JavaScript – Handles searching, category filtering, price sorting, and cart functionality.

Bootstrap 5 – Provides responsive layouts, grid systems, and UI components.

🚀 Key Functionalities

1. Product Search

Users can search for products by name to quickly find the items they want.

2. Category Filtering

Users can select a product category to view relevant products in the catalog.

3. Price Sorting

Products can be sorted using two options:

Low to High – Displays lower-priced products first.

High to Low – Displays higher-priced products first.

4. Shopping Cart Management

Users can:

Add products to the cart.

Increase product quantities using the plus (+) button.

Decrease product quantities using the minus (−) button.

Remove products from the cart.

Manage quantities of individual cart items.

5. Responsive User Interface

The catalog adapts to different screen sizes, providing a smooth browsing experience on desktops, laptops, tablets, and mobile devices.
